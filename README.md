# Nexora Local releases

Public Windows installers and automatic update files for Nexora Local.

Download **Nexora Local Setup** from [Latest release](https://github.com/nexorasol123-dotcom/nexora-local-releases/releases/latest). Close Nexora before installing an update and keep a backup of your shop data. Existing local data and the machine license are retained by upgrades.

Older installations that point to the private release repository must manually install version 1.2.4 once. Later setup-installed releases can use **Help → Check for updates**. Portable copies require manual replacement.

See each release's notes for changes and known limitations. This repository does not contain application source code, customer data, or private license keys.
